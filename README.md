# みやび AIライティングスタジオ

40代・50代・60代以上の女性に向けた「みやびのnote」の記事を、経験や思いを大切にしながら作成・管理するアプリです。

現在は **第1段階**：記事を手動で書き、編集・保存して、noteへ投稿する準備ができます。APIキーなしで全機能を利用でき、この段階では外部AIサービスへの通信やAPI料金は発生しません。既存のPythonアプリはそのまま残しています。

## Windowsでのインストールと起動

ZIP配布版では、先に「はじめに.txt」をお読みください。Python 3.11以上をインストールし、ZIPを「すべて展開」した後、`start_windows.bat` をダブルクリックすると、仮想環境の作成・初回の依存導入・起動を順に行います。仮想環境の有効化やPowerShellの設定変更は不要です。次回からは依存定義が変わった場合だけインストールを再実行します。Windows実機でのランチャー動作確認は未実施です。

1. Python公式サイトから **Python 3.11以上（3.12推奨）** をインストールします。インストーラーの「Add python.exe to PATH」を選んでください。
2. このプロジェクトをダウンロード・展開し、`app.py` のあるフォルダーを開きます。エクスプローラーのアドレス欄に `powershell` と入力してEnterを押すと、その場所でPowerShellを開けます。
3. 以下を1行ずつ実行します。最初のインストールにはインターネット接続が必要です。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

4. 起動時に表示されるLocal URLをブラウザーで開きます。初回にメールアドレスを尋ねられた場合は、未入力でEnterを押して進められます。
5. 終了するときは記事を保存してからPowerShellで `Ctrl+C` を押します。

PowerShellの実行ポリシーで `Activate.ps1` が拒否された場合は、ポリシーを変更せず、次のコマンドで同じ仮想環境を使えます。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

次回からはプロジェクトのフォルダーで次を実行するだけです。

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Pythonが見つからない場合はPythonをインストールしてPowerShellを開き直してください。`python` の代わりに `py -3.12` で仮想環境を作成する方法もあります。ポート使用中の場合は起動コマンドの末尾に `--server.port 8502` を追加します。

## 基本操作

1. 左側メニューの「新しい記事」から、タイトルと本文を入力します。仮のタイトルだけでも保存できます。
2. ジャンル、対象読者、キーワード、検索意図、構成、ハッシュタグ、ステータス、公開日、note記事URL、備考も記録できます。
3. **「記事を保存」** を押し、保存成功の表示を確認します。
4. 「記事一覧」でタイトル・本文・キーワードを検索したり、ステータスで絞り込んだり、並べ替えたりできます。「編集」で続きを書けます。
5. 「複製」は元の記事を残してコピーを作ります。コピーのステータスは「アイデア」になり、公開日とURLは空欄になります。
6. 「削除」は確認チェックと「削除を確定する」の後に実行します。削除は取り消せません。
7. 「出力・投稿準備」でMarkdown（`.md`）またはテキスト（`.txt`）をダウンロードします。コピー用欄をクリックし、`Ctrl+A` → `Ctrl+C` でコピーもできます。noteへの貼り付け・投稿は手動です。

本文は `## 見出し` などのMarkdown記法を使えます。出力に含まれるのはタイトル・本文・ハッシュタグだけで、備考や検索意図・構成は含みません。テキスト出力は見出し・太字・リンクの基本的な記法を読みやすく変換しますが、表などすべてのMarkdown記法の変換は行いません。

「出力・投稿準備」は保存済みの記事を使います。編集中の内容を保存せず退避したい場合は、編集画面の「入力中の文章を出力」を利用してください。コピー用欄の変更は記事へ反映されません。

## 入力の保持と保存エラー

- 編集内容は、同じブラウザーセッション内の画面移動では一時保持されます。左側の「下書きに戻る」から再開できます。
- **自動でSQLiteへ保存されるわけではありません。** 再読み込み・タブを閉じる・アプリ停止の前には必ず保存してください。未保存入力はその後復元できません。
- 保存に失敗した場合は入力を画面に残してエラーを表示します。保存先の権限や空き容量を確認し、必要ならダウンロードで退避してから再試行してください。
- 保存はSQLiteトランザクションで行います。失敗しても以前に保存した記事を削除しません。
- 別のタブやセッションで同じ記事が更新・削除された場合は、古い内容で上書きせずエラーにします。入力を出力して退避し、ブラウザーを再読み込みして記事を開き直してください。

## 保存先と個人情報

既定では `app.py` と同じフォルダー内の `data/miyabi.sqlite3` にローカル保存します。作成日・更新日は日本時間で記録します。

保存先を変えたい場合は `.env.example` を `.env` という名前でコピーし、`MIYABI_DATA_DIR` を編集してアプリを再起動します。Windowsでも `/` 区切りのパスが使えます。

```dotenv
MIYABI_DATA_DIR=C:/Users/YourName/Documents/MiyabiData
```

相対パスは `app.py` のあるフォルダーが基準です。保存先の変更だけでは既存データは移動しません。アプリを停止し、既存のデータベースを新しい保存先へコピーしてください。`.env`、SQLiteファイル、APIキーはGitへ登録しない設定です。独自の保存先やバックアップを公開フォルダーへ置かないでください。

第2段階に向けて `.env.example` に `OPENAI_API_KEY` 欄を用意しています。今は空欄で構いません。将来設定するときもソースやチャットへキーを貼り付けず、環境変数またはローカルの `.env` へ設定します。既に存在する環境変数が `.env` より優先されます。

このアプリは個人のパソコンで使う想定です。ログイン機能や通信の暗号化は実装していないため、個人情報を含むデータを扱う状態でインターネットに公開しないでください。

## 手動バックアップ・復元

バックアップ画面は第4段階で追加予定です。現在は以下の方法で保管してください。

1. 全記事を保存し、アプリを `Ctrl+C` で停止します。他の起動中プロセスも終了します。
2. `data/miyabi.sqlite3`（保存先を変更した場合はそのフォルダー内の同名ファイル）を、安全な別フォルダーへ日付付きでコピーします。
3. 復元時もアプリを停止し、現在のファイルを別途退避してから、コピーしたファイルを元の場所へ `miyabi.sqlite3` として戻します。

Markdown出力は記事本文の持ち出し用で、全項目のバックアップではありません。

## 開発とテスト

```powershell
python -m unittest discover -s tests -v
```

テストは一時フォルダーのデータベースを使い、実際の記事は操作しません。SQLiteの作成・編集・再接続後の永続化・検索・複製・削除・入力検証・同時編集・トランザクション失敗、出力内容と、Streamlitの画面操作・保存失敗時の入力保持を確認します。

実行確認環境：Linux / Python 3.12。Windows用のパス処理と依存関係を用いていますが、Windows実機での実行確認は未実施です。

## フォルダー構成

```text
app.py                  起動入口・環境変数の読み込み
miyabi/
  database.py           SQLite操作・入力検証
  ui.py                 日本語UIと下書き保持
  export.py             Markdown／テキスト出力
  ai_client.py          将来のAPI連携用境界（第1段階は通信なし）
tests/
  test_database.py      データ保存・出力テスト
  test_ui.py            画面操作テスト
requirements.txt        必要パッケージ
.env.example            環境変数の見本
.gitignore              個人データの除外設定
README.md               本書
```
