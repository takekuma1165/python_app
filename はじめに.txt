みやび AIライティングスタジオ ― はじめに

1. 先に Python 3.12 をインストールします。
   https://www.python.org/downloads/windows/
   Python 3.12 の Windows installer (64-bit) を選んでください。
   インストール画面で「Add python.exe to PATH」にチェックを入れます。
   すでに Python 3.11 以上があれば、そのまま試せます。

2. ダウンロードしたZIPを右クリックし「すべて展開」を選びます。
   ZIPの中で直接起動せず、展開したフォルダーを開いてください。

3. start_windows.bat をダブルクリックします。
   初回は必要なパッケージをインストールします。
   インターネットに接続して数分お待ちください。

4. ブラウザーが開いたら「新しい記事」から書き始められます。
   開かない場合は、黒い画面に表示された Local URL をブラウザーに入力します。
   通常は http://localhost:8501 です。実際に表示された番号を使ってください。
   初回のメールアドレス入力は空欄でEnterを押して進められます。

5. 「記事を保存」を押して保存します。
   終了するときは保存してから黒い画面で Ctrl+C を押します。
   次回も start_windows.bat をダブルクリックするだけです。

記事はフォルダー内の data/miyabi.sqlite3 に保存されます。
フォルダーを削除すると保存した記事も失われるため、大切に保管してください。
APIキーは不要です。この第1段階にはAI生成機能はまだありません。

エラーが出た場合は黒い画面を閉じる前に内容を控えてください。
詳しい使い方・バックアップ方法は README.md に記載しています。
